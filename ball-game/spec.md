# 网页抓小球小游戏 —— 需求规格文档 (spec.md)

**项目阶段：** ① Brainstorming 需求研讨（已确认 2026-10-21）
**技术栈：** 原生 HTML + CSS3 + JavaScript（三文件分离）
**浏览器兼容：** Chrome / Edge / Firefox 最新两版

---

## 1. 项目概述

一款基于 DOM 的网页抓小球小游戏，玩家在限定 2 分钟时间内点击屏幕上随机出现的蓝色小球得分，同时需避免误点空白区域扣分。

---

## 2. 文件结构

```
ball-game/
├── index.html      # 页面结构
├── style.css       # 所有样式
└── script.js       # 游戏逻辑
```

---

## 3. 视觉规格

| 元素 | 规格 |
|------|------|
| 页面背景 | 柔和奶黄 `#FFF9C4` |
| 游戏容器 | 居中容器，尺寸 **800 × 600px** |
| 小球 | 固定直径 **50px**、纯浅蓝色圆形 `#4FC3F7` |
| 小球活动区 | 游戏容器内、顶部分数栏以下的全部区域 |
| 小球边缘内边距 | 距离游戏容器四边各 **20px**（保证不贴边）|

---

## 4. 游戏流程状态机

```
[初始状态] ──点击 Start──▶ [3-2-1-Go! 倒计时] ──Go!──▶ [正式游戏中] ──时间到──▶ [游戏结束]
    │                                                        │                        │
    │  Start 按钮可见                                        │  Start 按钮隐藏         │  显示"再来一局"按钮
    │  小球不存在                                            │  小球活动区有 1 个小球  │  停止刷新小球
    │  倒计时显示 "2:00"                                     │  倒计时递减             │  显示最终得分
    │  分数显示 "0"                                          │  实时更新分数           │  分数冻结
```

---

## 5. 交互规则详表

| 场景 | 行为 |
|------|------|
| 点击小球（游戏中） | **+2 分**，小球消失 → 在活动区内随机位置生成新小球 |
| 点击游戏容器内**空白区域**（游戏中） | **-1 分**，小球位置不变 |
| 点击**游戏容器外**区域（游戏中） | **不扣分** |
| 点击顶部**分数栏**（游戏中） | **不扣分**（属于界面控件区） |
| 点击**倒计时显示区**（游戏中） | **不扣分** |
| 点击**Start 按钮** | 触发 3-2-1-Go! 倒计时，同时 Start 按钮隐藏 |
| 3-2-1-Go! 倒计时期间 | 不出现小球、点击任何区域不记分、不扣分 |
| 倒计时归零 | 小球停止刷新，弹出"时间到！最终得分：X"，显示"再来一局"按钮 |
| 点击"再来一局" | 分数归零、小球重置、重新走 3-2-1-Go! 倒计时 |
| 分数下限 | **允许变成负数**（无下限保护） |
| 小球数量 | **始终同时存在 1 个**，点消失后立即刷新新位置 |

## 6. 计分与计时规格

| 项目 | 规格 |
|------|------|
| 正式游戏时长 | **120 秒（2 分钟）** |
| 倒计时格式 | `MM:SS`，如 `2:00` → `1:59` → `...` → `0:00` |
| 3-2-1-Go! 倒计时 | 每个数字显示 1 秒，最后显示 `Go!` 0.5 秒后切正式游戏 |
| 初始分数 | **0** |
| 点击小球 | **+2** |
| 点击游戏容器内空白 | **-1** |
| 分数显示位置 | 游戏容器**顶部左**，实时更新 |
| 倒计时显示位置 | 游戏容器**顶部右**，实时更新 |

## 7. 边界决策（已用户确认）

| # | 决策点 | 确认值 |
|---|--------|--------|
| ① | 游戏容器尺寸 | **800 × 600px** 居中布局 |
| ② | 游戏容器外（页面边缘）点击 | **不扣分**（只有容器内非小球区域才 -1）|
| ③ | 3-2-1-Go! 倒计时期间 | 不出现小球、点击不记分不扣分 |
| ④ | 分数栏 / 倒计时显示区点击 | **不扣分**（属于界面控件区）|
| ⑤ | "再来一局"行为 | 分数归零 + 重新走 3-2-1-Go! |

---

## 8. 验收标准（概览）

1. 打开页面看到 Start 按钮 + 分数 0 + 倒计时 2:00，无小球
2. 点 Start → 3-2-1-Go! → 小球出现 + 倒计时递减
3. 点击小球 +2 分，小球刷新新位置
4. 点击容器内空白 -1 分，点击容器外不扣分
5. 2 分钟到点 → 显示最终得分 + 再来一局按钮
6. 再来一局 → 分数归零 + 重新倒计时

## 9. 命名规范（zxy 前缀强制规则）

> 生效日期：2026-10-23。**全程严格遵守，禁止跳过。**

| 类型 | 规则 | 示例 |
|------|------|------|
| HTML id | 必须以 `zxy_` 开头 | `id="zxy_gameContainer"` |
| HTML class | 必须以 `zxy_` 开头 | `class="zxy_scoreBar"` |
| CSS 选择器 | 所有类/ID 选择器以 `zxy_` 开头 | `.zxy_ball`, `#zxy_startBtn` |
| JS 全局变量 | 必须以 `zxy_` 开头 | `let zxy_score = 0;` |
| JS 局部变量 | 推荐以 `zxy_` 开头（可选，建议统一） | `const zxy_ballEl = ...` |
| JS 函数 | 必须以 `zxy_` 开头 | `function zxy_spawnBall() {}` |
| 常量 | 必须以 `zxy_` 开头（建议全大写） | `const ZXY_GAME_DURATION = 120;` |

**HTML 首页返回规则：** 所有新建的 HTML 文件（非 index.html）必须在页面顶部加入返回首页的超链接入口，指向 `../index.html`（或对应相对路径）。

**提示词记录规则：** 每条用户提示词在执行前，必须以**附加模式**（不覆盖）写入 `zxy_prompt.md`，内容包含时间、模型、提示词原文。
