Swiper 11 · 第 7 种 effect · 答辩问答

creative「电影墙」追问与解答

课堂只讲了 slide / fade / cube / coverflow / flip / cards 六种成品效果。
creative 是唯一需要自己写变换参数的效果，下面是与它相关的问答记录。

1

creative 和另外六种 effect 的本质区别是什么？

▾
前六种是成品套餐：Swiper 内部已经写好了整套变换，你只给一个名字就能用。
creative 是半成品：它不预设任何动画，只提供 prev 和 next 两个"变换槽位"， 位移、角度、透明度、缩放全部由你填，所以课堂上没有讲——它需要你自己设计动画。
2

prev / next 的 transform 各控制什么？

▾
两者描述的都是非激活状态，不是"动画过程"。
prev：当前这张左边那一张待命时的姿态。
next：当前这张右边那一张排队时的姿态。
真正动起来的是 Swiper：切换时它把这两个姿态按进度插值到归零态 （translate: [0,0,0]、rotate: [0,0,0]、scale: 1）， 所以看起来才像"进场 / 离场"。
3

translate 里的百分号，是相对谁的？

▾
相对 slide 自身的宽度（X 轴）和高度（Y 轴），不是相对视口，也不是相对外层容器。
原因：这些值最终被写成 CSS 的 transform: translate3d(...)， 而 CSS 规范中 translate 百分比的基准就是元素自身的 border box。
本页 slide 宽度刚好等于 swiper 容器宽度，所以肉眼看着像"相对容器"； 一旦改成 slidesPerView: 3，同样写 78% 就只按"三分之一宽"计算了。
4

为什么 Z 轴只能写数字，不能写百分比？

▾
因为 CSS 的 translateZ() 不接受百分比——Z 轴朝向观察者，没有可参照的"长度"。 只能用 px：负值后退（配合 perspective 投影变小），正值前移（变大）。 这也正是电影墙纵深感的主要来源。
5

怎么让卡片转 20 度？

▾
rotate 是 [X, Y, Z] 三个角度。在屏幕平面上打转用的是第三位 Z。
把 prev.rotate 的第三位从 -10 改成 -20 即可：
rotate: [0, 0, -20], // 负值逆时针，正值顺时针
6

scale 和 translateZ 都能让卡片变小，区别在哪？

▾
translateZ 是真实纵深：配合 perspective 产生近大远小的透视，边缘会轻微变形，有"退到墙后"的立体感。
scale 是纯平面缩放：像把图片整体压小，没有透视，看起来"平"。
两者叠加，才有现在这种电影选片墙的层次。
∑

本页演示四实际使用的配置

▾
creativeEffect: { prev: { // 上一张：缩小、左移、带角度 translate: ['-58%', 0, -320], // X 相对 slide 宽度；Z 用 px，负值后退 rotate: [0, 0, -20], // 绕 Z 轴逆时针 20° scale: 0.72, opacity: 0.45, shadow: true }, next: { // 下一张：放大、从右侧推进 translate: ['78%', 0, 120], // Z 正值前移，视觉上更大 rotate: [0, 0, 8], scale: 1.06, opacity: 0.85, shadow: true }, limitProgress: 1 // 只定义紧邻的两张，更远的沿用同一姿态 }
