本次遇到的一个坑：验收视频在 iPhone 上不播放

现象

任务三、任务四插入了 mp4 验收视频，电脑 Chrome 能正常播放，但用 iPhone Safari 打开时视频区域是黑的，点播放按钮没反应，进度条也拖不动。

原因

问题不在视频文件，而在自己写的 db/server.js 静态服务上，缺了两样东西：

  1. 没有注册 mp4 的 MIME 类型：扩展名不在映射表里时，响应头会退回 application/octet-stream，浏览器把它当成「未知二进制文件」，不会按视频解析。
  2. 不支持 Range 分段请求：视频播放器不会一次性下载整段视频，而是先请求 Range: bytes=0-1023 拿到文件头信息。原代码永远返回 200 + 整个文件，Safari 拿不到 206 和 Content-Range，就判定「无法流式播放」，直接放弃。

解决

  1. 在 MIME 映射表里补上 '.mp4': 'video/mp4'、'.webm': 'video/webm'；
  2. 在静态文件服务里增加 Range 分支：解析请求头里的 bytes=start-end，返回 206，并带上 Content-Range、Content-Length、Accept-Ranges: bytes，用 fs.createReadStream(file, { start, end }) 只发这一段。

验证

命令 curl -H "Range: bytes=0-1023" 视频地址 返回 HTTP/1.1 206 Partial Content 与 Content-Range: bytes 0-1023/13602679；页面里 video.readyState = 4、duration = 5.92s、error = null。

结论

自己写静态服务器时，「能打开图片」不等于「能播视频」。视频依赖 MIME 类型 + Range 分段响应这两件事，缺一个在 iOS 上就静默失败——而且不报错，只是一片黑。
